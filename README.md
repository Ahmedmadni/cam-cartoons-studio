# Character Animator Studio

"أنا بحاجة لبناء تطبيق تفاعلي للأطفال لتوليد شخصيات كرتونية 3D تتحرك مع الكاميرا. ابدأ بإنشاء مشروع React مع 3 شاشات: (1) اختيار شخصية 3D, (2) فتح الكاميرا وتسجيل الفيديو مع تحريك الشخصية, (3) حفظ الفيديو. استخدم React Three Fiber و react-webcam. سنبدأ بالواجهة البصرية أولاً ثم نضيف الذكاء الاصطناعي لاحقاً."
